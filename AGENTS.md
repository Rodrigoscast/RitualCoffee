# Project design skills

For landing page and portfolio development, use the relevant locally provided skills from `skills/`. Read each skill's full `SKILL.md` when it applies, then load supporting files the skill references. User requests and existing codebase constraints take precedence.

- Construction and visual quality — `skills/impeccable/SKILL.md`, `skills/design-taste-frontend/SKILL.md`, `skills/high-end-visual-design/SKILL.md`
- Building motion — `skills/animate/SKILL.md`, `skills/emil-design-eng/SKILL.md`
- Visual composition and artwork — `skills/imagegen-frontend-web/SKILL.md`
- Final animation audits — `skills/improve-animations/SKILL.md`, `skills/review-animations/SKILL.md`

Use the construction skills when planning or implementing the landing page, animation skills when adding motion, and final review skills after implementation.
